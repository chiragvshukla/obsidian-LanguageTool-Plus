# Obsidian plugin fork

Reserved for the vendored AGPL-3.0 fork of
[Clemens-E/obsidian-languagetool-plugin](https://github.com/Clemens-E/obsidian-languagetool-plugin).

The fork lands in Phase 6 (see `docs/PLAN.md`). Until then, install the upstream
plugin and point it at the gateway.

When vendoring, record here:

- Upstream repository URL
- Exact commit SHA that was copied
- Upstream license (AGPL-3.0) and license file path
- Date of the copy
- List of local modifications

Do not add the plugin as a git submodule. See `docs/DECISIONS.md` (ADR-003).
